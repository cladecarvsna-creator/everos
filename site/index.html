EverOS

Операционная система, написанная с нуля на ассемблере и Rust. Загружается в рабочий стол 1920×1080, открывает сайты по HTTPS, хранит файлы на диске и переписывается в Telegram.

Возможности

Всё, что ждёшь от компьютера, только своё

Каждая часть написана для EverOS: драйверы, файловая система, оконная система, браузерный движок и клиент Telegram.

Рабочий стол в стиле Windows 11

Система сразу загружается в графический рабочий стол. Сглаженные шрифты, скруглённые углы, мягкие тени, и ничего не мерцает.

  • Окна перетаскиваются, сворачиваются в панель и плавно появляются
  • Меню Start с поиском по программам, клавиша Win
  • Виртуальные рабочие столы, Корзина, закрепление на панели

Экран блокировки и вход

Большие часы на экране блокировки, по клавише он уезжает вверх и открывает вход на размытом фоне. Неверный пароль встряхивает поле.

  • Несколько пользователей, у каждого своя папка C:\Users\имя
  • Пароли хранятся только как хеш с солью

Браузер со своим движком

EverBrowser открывает сайты по HTTP и HTTPS, разбирает HTML и CSS, раскладывает flexbox и grid и выполняет JavaScript. Страницы грузятся в фоне, рабочий стол при этом не замирает.

Файлы, Проводник и Блокнот

Драйвер жёсткого диска и FAT32 с длинными русскими именами. Файлы переживают перезагрузку, а тот же диск открывается в Windows и Linux.

  • Проводник: адресная строка, поиск, «Таблица» и «Значки», F2 и Del
  • Блокнот: UTF-8 и Windows-1251, отмена, выделение, Сохранить как

Telegram

Свой клиент в стиле Telegram Desktop, протокол MTProto 2.0 написан с нуля. Вход по номеру и коду, личные чаты, группы, каналы, фото, файлы и цветные эмодзи.

Ключи api_id и api_hash у каждого свои, их получают на my.telegram.org. В EverOS их нет.

Установка на диск

ISO запускает мастер установки: язык, лицензия, выбор диска, учётная запись. Установщик размечает диск, копирует ядро и ставит GRUB, после перезагрузки EverOS стартует уже с диска.

Можно и не устанавливать: кнопка «Попробовать EverOS» запускает систему прямо с ISO.

Сеть, Wi‑Fi и прокси

Сетевая карта Intel e1000, DHCP и DNS: в QEMU интернет работает без настройки. WPA2-Personal написан целиком, а в Параметрах есть HTTP и SOCKS5 прокси.

Темы и обои

Светлая и тёмная тема, цвет акцента, свои обои, анимации загрузки, перезагрузки и выключения.

Как запустить

Три шага до рабочего стола

EverOS запускается в виртуальной машине QEMU. Каждый раз, когда в репозитории появляется новый код, собирается свежий ISO.

  1. Скачайте файлы

    everos.iso и run-windows.bat, положите их в одну папку.

  2. Поставьте QEMU

    Для Windows установщик есть на qemu.org. Скрипт найдёт его в C:\Program Files\qemu.

  3. Запустите

    Дважды щёлкните run-windows.bat. Первый запуск откроет установщик, дальше EverOS стартует с диска everos-disk.vhd.

Linux и macOS

$ qemu-img create -f raw everos-disk.img 128M
$ qemu-system-x86_64 -cdrom everos.iso -boot order=cd -m 512M \
-drive file=everos-disk.img,format=raw,if=ide -nic user,model=e1000

Флаг -nic user,model=e1000 даёт EverOS интернет через сеть компьютера. Из исходников: make run.
